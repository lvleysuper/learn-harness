# 工具选型调研技能

## 触发条件

当用户提出以下类型的问题时激活：
- "X工具有很多，怎么选？"
- "帮我对比A、B、C..."
- "哪个X工具最好？"
- "帮我做个选型调研"

## 方法论

### 第1步：拆维度

把"哪个好"拆成独立评估维度，不要混排。

操作：
1. 识别工具的核心属性维度（如：能力、配置性、价格、生态、学习曲线）
2. 检查是否存在"工具层"和"底层引擎层"的区分（如AI工具=工具+模型）
3. 每个维度独立评估，不急于合并总分

输出：维度列表 + 每个维度的说明

### 第2步：找基准

为每个维度找到权威评测基准。

操作：
1. 搜索该领域的权威基准（官方排行榜、行业标准测试、学术论文）
2. 区分基准类型：人类偏好型（主观）vs 客观基准型（可量化）
3. 当两类基准矛盾时，同时呈现并解释差异原因
4. 标注数据来源和时效性

输出：基准对照表，含类型、方法论、权威性评级

### 第3步：多源交叉

聚合 5+ 独立评测来源，识别共识和分歧。

操作：
1. 搜索多个独立评测平台、博客、社区讨论
2. 制作交叉验证表：每个来源对每个工具的评分
3. 标记共识（所有来源一致）和分歧（来源间不一致）
4. 共识部分高置信，分歧部分需深入分析原因

输出：多源交叉验证表

### 第4步：找隐藏维度

发现大多数人忽略但对结果影响最大的维度。

操作：
1. 对比"同一维度不同选择"的影响幅度
2. 如果维度A的差异 >> 维度B的差异，A 就是隐藏关键维度
3. 用具体数据量化差异幅度（如"22分 vs 1-3分"）

输出：隐藏维度的发现 + 量化证据

### 第5步：场景映射

制作"场景 → 推荐"映射，而非单一排行榜。

操作：
1. 列出 5-10 个典型使用场景
2. 每个场景给出首选和备选
3. 用一句话说明理由

输出：场景决策矩阵表

### 第6步：组合方案

给出不同预算/需求下的黄金组合。

操作：
1. 设计 3-4 套方案（能力最大化、性价比最优、企业级、开源等）
2. 每套方案列出具体组合和月费
3. 标注适用人群

输出：组合方案表

## 反模式（必须避免）

- 不要只看一个排行榜就下结论
- 不要把不同维度混在一起排总分
- 不要忽略隐藏维度
- 不要只推荐一个"最佳"——不同场景需要不同工具
- 不要用空洞的方法论文本填充，每个步骤都要有具体数据和实例

## 输出结构

最终文档应包含：
1. 评估方式说明（维度、基准、方法论）
2. 工具/产品排行榜（多源交叉验证）
3. 底层引擎排行榜（如适用）
4. 场景选择建议
5. 关键特性深度对比（隐藏维度重点展开）
6. 市场格局总结
7. 选型建议与黄金组合
