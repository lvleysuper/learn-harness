# Learn Harness

AI编程工具 Harness Engineering 学习系统。

## 项目目标

建立系统化的 Harness Engineering 知识体系，从整体到细节，并结合学习系统构建可复用的 harness 工程，兼容 Claude Code、OpenCode 等主流工具。

## 学习框架：3层12问题

### 个人层
- P1: AI编程工具这么多，如何选择？
- P2: 工具很多，有哪些通用的、不变的东西？
- P3: Harness框架那么多，如何选择？如何分层配合？
- P4: 如何构建适合自己业务场景的个人插件？

### 团队层
- P5: 团队级Harness如何设计？
- P6: 多人协作的规范如何统一？
- P7: 如何评估Harness的效果？
- P8: 如何持续维护和演进？

### 项目层
- P9: 项目级配置的最佳实践？
- P10: 如何跨项目复用Harness？
- P11: 如何与CI/CD集成？
- P12: 如何构建组织级Harness资产库？
